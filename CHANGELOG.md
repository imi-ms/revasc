# Changelog

## [1.1.0] - 2026-10-02

### Changed
- Revised the set of procedure codes used to define the revascularization endpoint.
- Replaced REVASC ensemble model weights.
- Re-derived rule-in and rule-out thresholds for the updated model.

### Notes
All other cohort selection and endpoint-definition criteria remained unchanged.

This revision increased the number of REVASC-positive cases from 1,084/180,686 (0.60%) to 3,260/180,686 (1.80%).

Predictions obtained with REVASC v1.1.0 are not expected to be identical
to those obtained with v1.0.0.

The original model accompanying the European Heart Journal publication
is preserved as release v1.0.0.
